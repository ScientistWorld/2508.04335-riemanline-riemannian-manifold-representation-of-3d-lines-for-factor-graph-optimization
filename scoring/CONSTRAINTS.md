# Scientist Constraints

## Data
Use the fixed procedural dataset generated by `data/generate_synthetic.py` with the default seed and dimensions. Do not add external line observations, camera views, or additional ground-truth supervision when reporting scores for `scaled_synthetic_parallel_lines`.

## Evaluation
Submit artifacts in the same output format consumed by `eval/evaluate_outputs.py`: one JSON file per method under `outputs/`, containing estimated Plucker normal and direction vectors for each line. The evaluator must remain independent of `method/`.

## Parameter Accounting
Report the effective number of line parameters used by the submitted representation. The compactness metric is part of the score because the paper's claim includes lower parameter dimensionality.

## Compliance Checklist
- [ ] Default synthetic dataset seed and dimensions are unchanged
- [ ] No external observations or labels are used for the scored experiment
- [ ] `eval/` does not import from `method/`
- [ ] Output JSON reports estimated line normals, directions, and effective parameter count
