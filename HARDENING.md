This pass addresses both items in `REVIEW.md`: dataset-grounded joint evaluation, and demonstrated improvement on the paper's data. Final verification is pending the single combined job. This file will be completed from that job's recorded results before marking the workspace done. ## Changes decided from the reports

- Added the paper's joint pose/point/line optimization on public Open-Structure ICL-NUIM and TartanAir graphs, not an end-to-end surrogate. The existing shared sphere/circle line updates, reprojection factors, Cauchy loss, group inlier check and independent line baselines now participate in joint bundle adjustment. The solver performs 100 LM iterations at most with convergence checks and point Schur elimination. See `method/joint_ba.py` and the independent `baseline/` implementation. This restores a substantial missing part of the paper's procedure.
- Two dataset experiments score ground-truth trajectories and line landmarks: dataset associations, and associations clustered from initial estimates. Each has 24 held-out instances (six sequences, four keyframe phases, at most 150 keyframes). The latter addresses unreliable upstream structure on the paper's own observations. Train now has six disjoint sequences as well: office1 was restored to balance both splits at four ICL-NUIM and two TartanAir sequences. Same preprocessing, noise, scale and interface on both splits.
- TartanAir's provided exact projected measurements receive 1 px noise to avoid a zero-error estimation problem. ICL-NUIM retains its measured observations. Trajectory alignment is Sim(3), reflecting unobservable scale in the 2D-only factor graphs. Ground-truth lines and poses remain in `eval/test/`; only initial estimates and observations reach solvers.
- Closed the previously paying absolute-path read. Hiding a Python module in a workspace view was insufficient. The solver process now enters an unprivileged Landlock filesystem restriction before executing its script. Public assets are readable; input/output and temporary directories are writable; `eval/test/` is inaccessible through either relative or absolute paths, including its downloaded public ground-truth archives. The evaluator retains its own access. This is an answer-file boundary, not a restriction to reference solver settings. A lightweight check read public method code successfully and received PermissionError for the absolute hidden generator path. Kernel Landlock ABI >= 3 is required; failure is closed and recorded as a failed run.
- Removed the evaluator's three-hour solver wall-clock cutoff. Iteration/convergence limits define work; elapsed seconds are logs only. The reference and all controls are run sequentially with one BLAS thread, with nothing else scheduled alongside them by this script.
- Reject oversized output JSON before parsing (16 MiB), wrong list lengths, and read only log tails on failure, avoiding trivial resource exhaustion during scoring.
- Reject finite raw vectors whose normalization overflows, and reject impossible aggregate values. Missing or invalid poses, lines, outputs, and task failures receive complete worst-value vectors in every experiment. Baseline source and launchers are pinned by independent evaluator manifests; solver execution cannot rewrite them. The evaluator owns the inputs, truth, thresholds, test sizes and comparisons.
- Fixed paired analysis to handle both joint experiments, assert matching instance ids, include failed attempts in the standard deviations of cohorts that rank them, and report both instance-paired and sequence-block-paired confidence intervals. Repeated phases of one sequence are not presented as independent sequences.
- Removed a second leak: public per-line test error vectors from several known estimators could constrain the true lines, and per-scene summaries exposed experiment assignments. Detailed test records and raw predictions now stay exclusively under `eval/test/`; public canonical scores and archived red-team reports retain aggregate metrics only.
- Preserve private raw test outputs under gitignored `eval/test/outputs/`, enabling later evaluator-only rescoring. Earlier test outputs were deleted by the evaluator, so this pass must rerun them. Reference and baselines are rerun end to end from final code, followed by variants and affected shortcuts in isolated workspace copies. Canonical scores contain only reference plus baseline rows; shortcut metrics stay in the red-team report.

## Headroom and limitations

The existing procedural robustness experiment remains; it is not the sole evidence of headroom. The clustered dataset experiment tests a real weakness of accepting unreliable associations. Verification includes variants that perform statistical membership checking followed by joint refinement, rather than choosing among frozen reference outputs. They must improve on identical held-out inputs beyond paired uncertainty and remain away from metric bounds. The reference sits exactly at the structural parameter-error bound only in the clean procedural experiment. No angular, unseen-view or trajectory metric is at its lower bound.

The present dataset runs show the paper's line-accuracy and compactness benefit clearly, but mixed trajectory changes: there is no claim that every sequence or aggregate ATE improves over every independent baseline. Full-sequence paper ATE gains and runtime claims remain unverified. Keyframe restriction, finite-difference local line/pose Jacobians and Python LM replace full-frame Ceres execution for compute reasons; manifold updates and optimization factors remain the actual method. Associations from initial clustering and procedural mislabeled groups extend the paper's assumed associations. These are stated limitations, not reported paper replications.

Legitimate Sim(3) gauge transformations and rerunning the identical solver should tie. Bogus metadata is ignored; when attached to valid reference geometry it ties because the actual reconstruction still had to be computed. Rewriting a solver's own input copy is ignored by scoring. These do not give a method free geometry. The original two-view enumeration shortcut already lost in `REDTEAM.md`; its finite candidate enumeration does not solve the present joint graphs or truncated-segment tasks. It is not replayed. General continuous optimization on the input observations is allowed research, not a counted-query budget that public objective code can bypass. Sophisticated attacks on the kernel boundary are left to the separate shortcut grader; no defenses against leftover processes or Python environments are added.
